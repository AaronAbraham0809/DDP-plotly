Plotly Interactive Plot: Sepal Length vs. Petal Length

This repository contains an R Markdown file that generates an interactive plot using Plotly to visualize the relationship between Sepal Length and Petal Length from the iris dataset. The plot is color-coded by species, providing an insightful view of how different species of flowers vary in these two dimensions. The output of the R Markdown file is an HTML document that features an interactive scatter plot.

Key Features:
Interactive visualization with Plotly
Display of Sepal Length vs. Petal Length
Color-coded by flower species
Generated using the iris dataset

About the Iris Dataset:
The iris dataset is a well-known dataset in R, frequently used for demonstrating various data analysis techniques. It contains 150 observations of iris flowers, with 5 attributes:

Sepal Length
Sepal Width
Petal Length
Petal Width
Species


You can load the dataset directly in R using the following code:

data(iris)
